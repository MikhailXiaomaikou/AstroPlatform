# Hidden Paper Record — TEMPLATE

A template for the per-paper hidden record used in blind research testing
(see [BLIND_RESEARCH_TESTING_LOG.md](./BLIND_RESEARCH_TESTING_LOG.md)).

> **Keep filled-in records OUTSIDE the prompt context.** Never paste the title,
> arXiv ID, DOI, conclusion, or key numbers into the Chat UI during a blind run.
> Store completed records in a private location — not committed to this repo,
> not in any prompt or tool input. This file is only the empty scaffold.
