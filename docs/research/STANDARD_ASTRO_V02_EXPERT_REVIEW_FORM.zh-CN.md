# Standard Astro v0.2 专家盲评记录表

## 评审说明

- 评审对象：12 组匿名 A/B 回答。
- 建议时长：约 30 分钟，每组 2–3 分钟。
- 回答顺序已随机化；评审包不显示模型、条件、路由和系统状态。
- 不要求重做整篇论文，只判断回答能否作为可靠的研究起点。
- 请记录具体错误或缺项，不用“总体不错”替代证据。

## 每组必填项

| 字段 | 可选值 / 说明 |
|---|---|
| 科学正确性 | A / B / 相当 / 两者均需修改 |
| 方法适用性 | A / B / 相当 / 两者均不适用 |
| 边界说明是否有用 | A / B / 相当 / 两者均不足 |
| 更愿意复用 | A / B / 都不选 |
| 严重科学错误 | A / B / 两者 / 无 |
| 无需科学性修改即可作为研究起点 | A / B / 两者 / 无 |
| 具体修改意见 | 指明错误主张、缺失假设、错误方法或需要补充的证据 |

## 汇总门槛

- Standard Astro 严重科学错误：`0`。
- 至少 `10/12` 组的 Standard Astro 回答无需科学性修改即可作为研究起点。
- 至少 `8/12` 组优先选择 Standard Astro。
- 每条专家修改意见都应回填为可复现失败案例。
